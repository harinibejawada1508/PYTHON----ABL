# Python Activity-Based Learning (ABL)

This folder contains 10 beginner-friendly Python case studies for first-year students.

## Programs
1. Attendance Recovery Computation
2. Multi-Day Water Tank Simulation
3. Fuel Consumption and Route Comparison
4. Numeric Diamond Pattern Generator
5. Password Policy Validation
6. Student Feedback Sentiment Scoring
7. Nested Loop Calendar Generator
8. Student Marks Matrix Analysis
9. Weekly Electricity Consumption Matrix
10. Food Waste Monitoring System

## How to run
Install Python 3, open a terminal in a program's folder, and run:
`python main.py`

Each case study has its own README with a short description and example usage.
